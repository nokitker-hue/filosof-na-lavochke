# Философ на лавочке

Медитативная экзистенциальная визуальная новелла об уставшем программисте,
озере, лавочке и людях, которые оказываются рядом.

Один файл `index.html`. Без сборки, без npm, без внешних картинок.
Открывается двойным кликом — и работает.

## Как играть

1. Откройте `index.html` в браузере.
2. Читайте. Клик по тексту (или пробел) — показать сцену сразу.
3. Выбирайте вариант кнопкой или цифрами `1–4`.
4. «Персонажи» — портреты и отношения. «Сохранения» — три ручных слота.
5. «Заново» — начать историю с первого заката.

## Что внутри

- 4 дня, 90+ сцен, ветвление и восемь основных персонажей
  плюс рыбак, собака, смотрительница и курьер.
- 6 финалов: «Светлое озарение», «Погасший вид», «Парадокс»,
  «Равновесие», «Ты сам» и секретный «Улов».
- Отношения от −5 до +5, флаги выборов и финал, который зависит
  не только от последнего клика.
- Удочка, рыбалка и то, что клюёт только тогда, когда не клюёт.
- CSS-фоны (закат, ночь, рассвет, дождь, туман) и встроенные SVG-портреты.
- Автосохранение после каждой сцены и три ручных слота в `localStorage`.

## Публикация на GitHub Pages

В папке есть `publish.js`. Ему нужен classic personal access token
со scope `repo`, положенный в `.ghtoken` рядом со скриптом:

```powershell
node publish.js
```

Скрипт создаст репозиторий `filosof-na-lavochke`, загрузит игру,
включит Pages и выведет ссылку вида
`https://<username>.github.io/filosof-na-lavochke/`.

Если не хочется запускать скрипт: создайте публичный репозиторий,
загрузите в корень `index.html`, `README.md` и `.nojekyll`,
затем включите Pages для ветки `main` и папки `/ (root)`.
